Janus

A modular data kernel in Rust

Protocols, storage engines, and cache building blocks behind a small execution core — not a drop-in replacement for existing databases.

GitHub Get started

What it is

Janus explores a layered design: transport, protocol, serializer, kernel, and storage. The first milestone targets TCP + RESP with an in-memory key/value store for SET, GET, and DELETE.

What it is not

  • A Redis or PostgreSQL replacement
  • Production-ready in early versions
  • A full Redis command set or clustered topology on day one

Quick start

Run from source or with Docker. Default listen address: 0.0.0.0:6380.

Cargo

git clone https://github.com/samuelfabel/janus.git
cd janus
cargo test
cargo run --release -- --bind 127.0.0.1:6380

Docker

docker build -t janus:local .
docker run --rm -p 6380:6380 janus:local
